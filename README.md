Number Guessing Game

Description

This is a simple Python game where the computer generates a random number between 1 and 100, and the user guesses the number until they find the correct answer.

Features

- Generates a random number.
- Gives hints if the guess is too high or too low.
- Counts the number of attempts.
- Handles invalid inputs.

Technologies Used

- Python
- Random module

How to Run

1. Install Python.
2. Open the project in VS Code.
3. Run the following command:

"python3 number_guessing.py"

Concepts Learned

- Variables
- While loops
- If-else conditions
- Random number generation
- User input and exception handling

Output

The program displays hints for each guess and congratulates the user when the correct number is found, along with the total number of attempts.
